Fork It Open

Fork It Open is an independent YouTube channel of short animated explainers about everyday science and technology: how GPS finds you, why the last 20% of a battery charges slowly, how a microwave heats food.

Channel: https://www.youtube.com/@forkitopen

Fork It Open publisher

The channel owner uses a small internal tool, "Fork It Open publisher", to upload and schedule the channel's own videos (title, description, thumbnail, subtitles and translations) through the YouTube Data API, and to read the channel's own statistics through the YouTube Analytics API for a private daily report. The tool has a single user, the channel owner, and is not offered to anyone else.

This tool uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API). See the YouTube Terms of Service and the Google Privacy Policy.
